# Shizuoka travel planner

A personal travel planner for two people, November 22–24, 2026.

- Dates, course and restaurant selection, local bookmarks and Google Maps routes.
- Photographs, styles, JavaScript and trip data are included in index.html.
- Choices are stored in each visitor’s browser; they are not synchronized between visitors.
- Maps, YouTube and source links require internet access.
- Accommodation and the exact return flight are not confirmed; the planned flight is around19:00 fromFSZ.
- Image and video credits and official timetable links are included in the page.

This is a personal itinerary proposal, not a booking confirmation.
